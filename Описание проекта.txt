ТЕХНИЧЕСКОЕ ЗАДАНИЕ
Проект: Веб-приложение "Weather App" на Flask


1. ОБЩАЯ ИНФОРМАЦИЯ

Название: Weather App
Цель: Веб-приложение для просмотра текущей погоды и прогноза по выбранному городу через внешний API.
Язык: Python 3
Framework: Flask


2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

2.1 Основной функционал
- Ввод названия города
- Текущая погода: температура, влажность, скорость ветра, описание, иконка
- Прогноз на несколько дней
- История запросов

2.2 Авторизация
- Регистрация, вход, выход
- Хранение данных пользователя в БД

2.3 Личный кабинет
- История поиска
- Добавление/удаление городов в избранное

2.4 REST API
GET /api/weather/{city}
Ответ: {"city": "Moscow", "temperature": 20, "humidity": 75}


3. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

Backend:   Python 3, Flask, Flask-SQLAlchemy, Flask-Login, Requests
Frontend:  HTML5, CSS3, Bootstrap 5, Jinja2
БД:        SQLite
Внешний API: OpenWeatherMap (openweathermap.org/api)
